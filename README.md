# Lava Legends — local dev

This is the local source for the "Lava Legends: Catch & Survive" Vite + React project.

## Quick start

Requirements: Node.js (16+) and npm.

```powershell
cd <project-folder>
npm install
npm run dev
```

Open http://localhost:5173 (or the URL printed by Vite) to view the app.

## Technologies

- Vite
- React + TypeScript
- Tailwind CSS
